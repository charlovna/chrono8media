   File: src/components/SectionNav.astro

Previous implementation was a right-edge vertical dot column hidden on

  - Reduced motion: all transitions disabled, no pip animation.

2. HERO ANIMATIONS — FIVE UNIQUE MECHANICAL MOTIONS
   File: src/motion/hero.ts, src/components/Hero.astro
-----------------------------------------------------------------------

Problem: previous animations were visually similar (variations of
opacity fades). User required each element to use a mechanically
distinct motion technique. Scramble text removed entirely.

Motion assignments (no two share a mechanic):
  1. Brand "CHRONO8 MEDIA"
       Technique: letter-spacing expansion (tight 0.06em to wide 0.18em)
       combined with opacity. Brand settles into place like a stamp.

  2. Headline line 1 "YOUR PARTNER IN"
       Technique: GSAP TextPlugin typewriter, char-by-char.
       A blinking caret (.tw-caret) leads the typing cursor.

  3. Headline line 2 "DIGITAL MARKETING."
       Technique: GSAP TextPlugin typewriter (caret carries over from
       line 1). On complete, innerHTML is restored so the <em> italic
       emphasis on "DIGITAL MARKETING" reappears cleanly.

  4. Sub paragraph
       Technique: CSS clip-path mask wipe, left to right curtain reveal.
       expo.inOut easing. Text is not animated char-by-char; the whole
       block reveals as a clean sweep.

  5. CTA button "Get Started"
       Technique: smooth slide-up from translateY(40px) + scale(0.95)
       to resting position. expo.out ease. No bounce, no elastic.

Ghost logo (behind headline): fades from 0 to 0.08 opacity across 1.6s
(sine.out) overlapping with the brand entrance. Unchanged from before.

3D logo float (right column): idle requestAnimationFrame loop and cursor-
tilt on desktop. Unchanged.

Reduced motion: all entrance animations skipped. Final state rendered
immediately. Caret hidden via CSS.

Implementation note: TextPlugin typewriter flattens innerHTML (removes
<em> tags) during typing. The italic emphasis is preserved by stashing
line.innerHTML before the typewriter runs and re-instating it in
onComplete. The plain text types first; the styled HTML restores the
moment typing finishes on that line.

4. SECTION HEADING ANIMATIONS — TYPEWRITER REPLACES SCRAMBLE
   File: src/motion/scroll.ts
-----------------------------------------------------------------------

Previous: section h2 headings scrambled in (random uppercase chars
revealing final text) via a vanilla scramble helper on scroll entry.

Replaced with: GSAP TextPlugin typewriter on scroll entry (same
technology as the hero headline). Each section heading's two .line spans
type in sequentially: line 1 completes, then line 2 begins 80ms later.

If a .line contains <em> markup (italic emphasis), the same stash-and-
restore pattern used in hero.ts applies: plain text types, innerHTML is
restored in onComplete so italic renders the moment the word finishes.

Trigger: ScrollTrigger, start 'top 82%', once: true.
Duration per line: capped at max(0.4s, character_count * 0.04s).

src/motion/scramble.ts remains in the codebase but is no longer called
from any production path. Can be deleted in a cleanup pass.
